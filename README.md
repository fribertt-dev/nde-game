# No Despiertes Eso (nde-game)

Juego multijugador cooperativo de sigilo, aventura y comedia hecho en Unreal Engine 5.7. Una banda de pequeños animales se infiltra en casas de criaturas gigantes para robar y escapar antes del amanecer.

## Requisitos
- Unreal Engine 5.7
- Blender 4.x
- Git y Git LFS (`git lfs install` antes de clonar)

## Clonar
```
git lfs install
git clone https://github.com/fribertt-dev/nde-game.git
```

Los binarios (`.uasset`, `.umap`, `.blend`, `.fbx`, texturas y audio) se guardan con Git LFS según `.gitattributes`. El editor usa el proveedor "Git (beta version)" de Unreal; el bloqueo de archivos queda pendiente hasta instalar el plugin Git LFS 2 si el equipo crece.

Lista de comprobación de herramientas: [docs/CHECKLIST_HERRAMIENTAS.md](docs/CHECKLIST_HERRAMIENTAS.md)
